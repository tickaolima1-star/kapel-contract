# Brainstorm to Plan

## Description

Turn an ambiguous feature request into an approved design and an executable implementation plan without starting implementation prematurely.

## Steps

1. Read `.agents/skills/brainstorming/SKILL.md` completely and invoke `brainstorming`.
2. Inspect the repository, then ask one clarifying question at a time until scope and success criteria are explicit.
3. Present two or three approaches with trade-offs and a recommendation.
4. Present the design, including architecture, boundaries, error handling, and verification, and obtain approval.
5. Save and review the approved specification as required by the skill.
6. Read `.agents/skills/writing-plans/SKILL.md` completely and invoke `writing-plans`.
7. Write a TDD-oriented plan with exact files, commands, expected failures, expected passes, and commit boundaries.
8. Stop before implementation until the plan or the user's prior instruction authorizes execution.
